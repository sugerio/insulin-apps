This glossary defines the words Knowledge and these docs use, A to Z. It is for anyone new to Knowledge, and for AI
agents that need precise meanings. For words about accounts, organizations and sign-in, see the
[platform glossary](/docs/platform/glossary).

## A

**AI assistant.** Claude, ChatGPT, Codex, Gemini and others, connected once in Settings › Connect AI, asking as their
person, with that person's access and no more.

**Already here.** Files with the same content as files the collection had already learned; nothing changed.

**API client.** A program the organization set up on insulinapps.com to call Knowledge. It reaches a collection only
when the collection is shared with it by name.

**Asleep.** A collection nobody asked for a while sleeps, to keep Knowledge free. The first question wakes it up, in
about a minute.

**Awake hours.** The time collections are awake: while people ask and shortly after, while learning, while exporting
and while kept ready. Each organization has a limit a month.

## B

**Backup.** A daily copy of a collection, kept for the organization's days of daily backups (30 by default); the
latest is kept as long as the collection exists.

## C

**Collection.** Files, web pages and notes about one subject, with its own owner, sharing and history.

**Collection role.** Owner, Admin, Editor or Viewer in one collection, from owning it, its general access or a share
by name.

**Correction.** A note that fixes a wrong answer or fact. The collection learns it, and the source it corrects is no
longer used for answers.

## F

**Fact.** One sentence taken from a file that a person can check.

## G

**General access.** The role everyone in the organization who can use Knowledge gets in a collection: Viewer, Editor or
none.

**Go back.** Make the collection answer from an earlier restore point. Later files are set aside, not deleted, and it
can be undone.

## H

**Hidden.** Removed before Insulin read the file, so no answer can show it.

## I

**Interrupted.** An import stopped part-way; nothing from it was kept, and Insulin tries again.

## K

**Keep it ready.** Stay awake during a daily window, so answers then take a few seconds.

## L

**Learning.** Insulin reads each file (reading) and works out the facts in it (understanding).

## N

**Needs attention.** What only a person can settle: files Insulin couldn't read, values hidden before learning,
reported answers, corrections to check.

**Note.** A few lines someone writes themselves, learned like a file and cited as a note.

## R

**Remove for good.** Delete a file and its text, so no earlier version can bring it back.

**Report.** Telling a collection's owner that an answer or a fact may be wrong. The answer shows it was reported until
someone checks it.

**Restore point.** A saved copy of the collection after every change, kept 30 days.

**Role in Knowledge.** Admin, Editor or Viewer, from the organization role or a role given for Knowledge only. It
decides whether someone can start collections and see Rules and data.

## S

**Set aside.** A file added after the version someone went back to: kept, not used, and ready to be added again.

**Source.** The exact words an answer is based on, with the file and the pages (or slides) they are on.

**Stop using.** Keep the file, but don't answer from it.

## V

**Viewer cap.** Someone whose role in Knowledge can only read acts as a Viewer in every collection, whatever it gives
them.

## W

**Waking up.** A sleeping collection starting again for a question: about a minute, or a few minutes from its backup
after 30 days unused.

**Won't guess.** What Knowledge says when nothing in the collection covers a question, instead of answering without a
source.
